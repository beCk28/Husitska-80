# Husitská 80 — WordPress Theme

Luxusní prezentační web pro multioborovou provozovnu na adrese Husitská 65, Praha 3 – Žižkov.

## Služby
- 🧵 Oprava oděvů
- 💇 Kadeřnictví Camelia
- 💅 Nehtové studio Anna

## Instalace

1. Zkopírujte složku `husitska-80` do `wp-content/themes/`
2. V administraci WordPressu aktivujte téma **Husitská 80**
3. Nastavte titulní stránku: Nastavení → Čtení → Statická stránka

## Požadavky
- WordPress 5.0+
- PHP 7.4+

## Technologie
- WordPress Custom Theme
- Tailwind CSS (CDN)
- Vanilla JS
